DeepSeek Harness Web Integration 帮助说明

DeepSeek Harness Web Integration 是什么？

DeepSeek Harness Web Integration 是一个 VSCode 扩展，用于在 VSCode 中集成 DeepSeek Harness (DSH) AI 编程助手。

它不是一个独立的 AI 工具，而是 DSH 的 VSCode 前端界面。两者之间的关系如下：

  • DeepSeek Harness (DSH)（@deepseek-ai/dsh）— 一个 AI 编程助手 CLI 工具，提供 Web 服务，负责实际的 AI 对话和代码处理。
  • DeepSeek Harness Web Integration（本扩展）— 将 DSH 的 Web 界面嵌入 VSCode 侧边栏，让你无需离开编辑器即可使用 DSH 的全部功能。

环境要求

DSH 依赖 Node.js 运行时。启动前扩展会自动检查 Node.js 环境：

  • 需要 Node.js >= 22.19.0，可通过以下命令验证版本：
node --version

若未安装 Node.js 或版本过低，启动时扩展会显示明确的错误提示。请安装或升级 Node.js 后重启 VSCode。

提示：若未全局安装 dsh 命令，扩展会自动使用 npx -y @deepseek-ai/dsh web 方式兜底启动，首次运行可能需要下载包，耗时较长。也可以开启 dsh-web.preferNpx 配置，始终优先使用 npx 方式启动（此方式启动失败不会回退到 dsh 命令）。

DSH 安装指南

全局安装为可选项（推荐，启动更快）。通过 npm 全局安装 DSH CLI 工具：

npm install -g @deepseek-ai/dsh

验证安装：

dsh --version

插件使用指南

启动 DSH

  1. 打开 VSCode 侧边栏的 DSH-Web 面板
  2. 点击"启动 DSH"按钮
  3. 等待服务启动完成
  4. 开始使用

连接外部 DSH 进程

如果你已经在终端或其他地方启动了 DSH 服务，可以让插件直接连接到该进程，无需重复启动。

  1. 打开 VSCode 设置（Ctrl+, / Cmd+,）
  2. 搜索 dsh-web.port，将端口号修改为外部进程正在使用的端口
  3. 重新打开侧边栏的 DSH-Web 面板

插件检测到对应端口已有 DSH 进程在运行时，会自动提示 "检测到外部 DSH 进程"，点击 "连接到进程" 即可直接加载 Web 界面。

常见问题

Q: DSH 无法启动？

A: 请检查端口 3080 是否被占用，或者尝试修改配置中的端口号。

Q: 连接超时怎么办？

A: 可尝试点击顶部栏的"重启进程"按钮，会杀掉 DSH 进程，重新启动。

Q: 已安装 DSH，但仍提示"DSH 未安装"？

A: 这可能是安装状态缓存导致的检测失败。请尝试：

  1. 点击侧边栏顶部的刷新连接按钮
  2. 如果无效，重启 VSCode（Ctrl+Shift+P → "Reload Window"）
  3. 验证安装：在终端运行 dsh --version

Q: DSH Web 界面的颜色与 VSCode 主题不匹配？

A: DSH Web 目前无法自动适配 VSCode 主题。需要在 DSH Web 界面的设置中手动切换颜色模式。
