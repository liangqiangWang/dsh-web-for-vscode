DeepSeek Harness Web Integration ヘルプ

DeepSeek Harness Web Integration とは？

DeepSeek Harness Web Integration は、DeepSeek Harness (DSH) AI コーディングアシスタントを VSCode に統合する拡張機能です。

  • DeepSeek Harness (DSH)（@deepseek-ai/dsh）— Web サービスを提供する AI コーディングアシスタント CLI ツール。
  • DeepSeek Harness Web Integration（この拡張機能）— DSH の Web インターフェースを VSCode サイドバーに埋め込みます。

動作環境

DSH は Node.js ランタイムに依存します。起動前に、拡張機能は Node.js 環境を自動的にチェックします：

  • Node.js >= 22.19.0 が必要です。次のコマンドでバージョンを確認できます：
node --version

Node.js がインストールされていない、またはバージョンが古い場合、起動時に拡張機能が明確なエラーメッセージを表示します。Node.js をインストールまたはアップグレードした後、VSCode を再起動してください。

ヒント：dsh コマンドがグローバルにインストールされていない場合、拡張機能は npx -y @deepseek-ai/dsh web による起動に自動的にフォールバックします。初回実行時はパッケージのダウンロードが必要なため、時間がかかる場合があります。また、dsh-web.preferNpx 設定を有効にすると、常に npx での起動を優先します（この場合、起動に失敗しても dsh コマンドにはフォールバックしません）。

DSH インストールガイド

グローバルインストールは任意です（推奨、起動が高速になります）。npm で DSH CLI ツールをグローバルインストール：

npm install -g @deepseek-ai/dsh

インストールの確認：

dsh --version

使用ガイド

DSH の起動

  1. VSCode サイドバーの DSH-Web パネルを開く
  2. 「DSH を起動」ボタンをクリック
  3. サービスの起動完了を待つ
  4. 利用開始

外部 DSH プロセスへの接続

ターミナル等で既に DSH サービスを起動している場合、新たにプロセスを起動せず直接接続できます。

  1. VSCode 設定を開く（Ctrl+, / Cmd+,）
  2. dsh-web.port を検索し、外部プロセスが使用するポート番号に変更
  3. サイドバーの DSH-Web パネルを再度開く

FAQ

Q: DSH インターフェースに貼り付けできない（初回の API Key 入力時など）？

A: これは VSCode の既知の問題（microsoft/vscode#129178）であり、本拡張機能のバグではありません。DSH Web インターフェースは VSCode 内にネストされた iframe として埋め込まれているため、macOS では Cmd+V などのショートカットが iframe 内の入力欄に届かないことがあり、貼り付けが不安定になったり、リフレッシュ後に回復したりすることがあります。

貼り付けができない場合は、以下の方法を順にお試しください：

  1. DSH の入力欄を一度クリックしてフォーカスを合わせてから Cmd+V を押す
  2. メニューバーの編集 → ペーストを使用する、または DSH の入力欄で右クリック → ペーストを行う
  3. DSH サイドバーパネル上部のツールバーにあるエディターで開くボタン（更新ボタンの隣）をクリックし、エディター領域で貼り付けを再試行する
  4. ... メニューのブラウザーで開くを選択（または http://localhost:3080 に直接アクセス）し、ブラウザーで API Key などを入力してから VSCode に戻る

Q: DSH が起動できない？

A: ポート 3080 が使用されていないか確認するか、設定でポート番号を変更してください。

Q: 接続がタイムアウトする場合は？

A: トップバーの「プロセスを再起動」ボタンをクリックしてください。

Q: DSH をインストール済みだが「DSH がインストールされていません」と表示される？

A: インストール状態のキャッシュが原因の可能性があります：

  1. サイドバー上部の接続を更新ボタンをクリック
  2. VSCode を再起動（Ctrl+Shift+P → "Reload Window"）
  3. インストール確認：ターミナルで dsh --version を実行
