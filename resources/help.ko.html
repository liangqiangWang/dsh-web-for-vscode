DeepSeek Harness Web Integration 도움말

DeepSeek Harness Web Integration 이란?

DeepSeek Harness Web Integration은 DeepSeek Harness (DSH) AI 코딩 어시스턴트를 VSCode에 통합하는 확장 프로그램입니다.

  • DeepSeek Harness (DSH)（@deepseek-ai/dsh）— 웹 서비스를 제공하는 AI 코딩 어시스턴트 CLI 도구.
  • DeepSeek Harness Web Integration（이 확장 프로그램）— DSH의 웹 인터페이스를 VSCode 사이드바에 포함합니다.

환경 요구 사항

DSH는 Node.js 런타임에 의존합니다. 시작하기 전에 확장 프로그램이 Node.js 환경을 자동으로 확인합니다:

  • Node.js >= 22.19.0이 필요합니다. 다음 명령으로 버전을 확인할 수 있습니다:
node --version

Node.js가 설치되어 있지 않거나 버전이 낮으면 시작 시 확장 프로그램이 명확한 오류 메시지를 표시합니다. Node.js를 설치하거나 업그레이드한 후 VSCode를 재시작해 주세요.

팁: dsh 명령이 전역 설치되어 있지 않으면 확장 프로그램이 자동으로 npx -y @deepseek-ai/dsh web 방식으로 시작합니다. 첫 실행 시 패키지 다운로드가 필요하여 시간이 걸릴 수 있습니다. 또한 dsh-web.preferNpx 설정을 활성화하면 항상 npx 방식으로 시작합니다(이 경우 시작에 실패해도 dsh 명령으로 대체되지 않습니다).

DSH 설치 가이드

전역 설치는 선택 사항입니다(권장, 시작이 더 빠릅니다). npm으로 DSH CLI 도구를 전역 설치:

npm install -g @deepseek-ai/dsh

설치 확인:

dsh --version

사용 가이드

DSH 시작

  1. VSCode 사이드바의 DSH-Web 패널 열기
  2. "DSH 시작" 버튼 클릭
  3. 서비스 시작 완료 대기
  4. 사용 시작

외부 DSH 프로세스에 연결

터미널 등에서 이미 DSH 서비스를 시작한 경우, 새 프로세스를 시작하지 않고 직접 연결할 수 있습니다.

  1. VSCode 설정 열기（Ctrl+, / Cmd+,）
  2. dsh-web.port를 검색하여 외부 프로세스가 사용하는 포트 번호로 변경
  3. 사이드바의 DSH-Web 패널 다시 열기

FAQ

Q: DSH 인터페이스에 붙여넣기가 안 됨 (처음 API Key 입력 시 등)?

A: 이것은 VSCode의 알려진 문제(microsoft/vscode#129178)이며, 본 확장 프로그램의 버그가 아닙니다. DSH 웹 인터페이스는 VSCode 내에 중첩 iframe으로 삽입되어 있어, macOS에서는 Cmd+V 등의 단축키가 iframe 내부의 입력란에 전달되지 않는 경우가 있습니다. 붙여넣기가 간헐적으로 작동하고 새로고침 후 복구될 수 있습니다.

붙여넣기가 작동하지 않으면 다음 방법을 순서대로 시도해 보세요:

  1. DSH 입력란을 한 번 클릭해 포커스를 맞춘 후 Cmd+V 누르기
  2. 메뉴 막대의 Edit → Paste 사용, 또는 DSH 입력란에서 우클릭 → 붙여넣기
  3. DSH 사이드바 패널 상단 도구 모음의 에디터에서 열기 버튼(새로 고침 버튼 옆)을 클릭한 후 에디터 영역에서 붙여넣기 재시도
  4. ... 메뉴의 브라우저에서 열기 선택(또는 http://localhost:3080 직접 접속) 후 브라우저에서 API Key 등을 입력하고 VSCode로 돌아오기

Q: DSH가 시작되지 않음?

A: 포트 3080이 사용 중인지 확인하거나 설정에서 포트 번호를 변경해 보세요.

Q: 연결 시간 초과 시?

A: 상단 바의 "프로세스 다시 시작" 버튼을 클릭해 보세요.

Q: DSH를 설치했는데 "DSH가 설치되지 않음"으로 표시됨?

A: 설치 상태 캐시가 원인일 수 있습니다：

  1. 사이드바 상단의 연결 새로고침 버튼 클릭
  2. VSCode 재시작（Ctrl+Shift+P → "Reload Window"）
  3. 설치 확인：터미널에서 dsh --version 실행
