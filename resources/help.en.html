DeepSeek Harness Web Integration Help

What is DeepSeek Harness Web Integration?

DeepSeek Harness Web Integration is a VSCode extension that integrates the DeepSeek Harness (DSH) AI coding assistant into VSCode.

It is not a standalone AI tool, but rather a VSCode frontend for DSH. The relationship between the two is as follows:

  • DeepSeek Harness (DSH) (@deepseek-ai/dsh) — An AI coding assistant CLI tool that provides a web service, handling the actual AI conversations and code processing.
  • DeepSeek Harness Web Integration (this extension) — Embeds DSH's web interface into the VSCode sidebar, allowing you to use all of DSH's features without leaving your editor.

Environment Requirements

DSH relies on the Node.js runtime. Before starting, the extension checks your Node.js environment:

  • Node.js >= 22.19.0 is required. Verify your version with:
node --version

If Node.js is missing or the version is too old, the extension will show an error message when starting. Please install or upgrade Node.js, then restart VSCode.

Tip: If the dsh command is not installed globally, the extension automatically falls back to starting DSH via npx -y @deepseek-ai/dsh web. The first run may need to download the package, which can take a while. You can also enable the dsh-web.preferNpx setting to always prefer the npx startup method (in that case, no fallback to the dsh command on failure).

DSH Installation Guide

Global installation is optional (recommended for faster startup). Install the DSH CLI tool globally via npm:

npm install -g @deepseek-ai/dsh

Verify installation:

dsh --version

Usage Guide

Launch DSH

  1. Open the DSH-Web panel in the VSCode sidebar
  2. Click the "Start DSH" button
  3. Wait for the service to start
  4. Start using it

Connect to an External DSH Process

If you have already started a DSH service in a terminal or elsewhere, the extension can connect directly to it without starting a new process.

  1. Open VSCode Settings (Ctrl+, / Cmd+,)
  2. Search for dsh-web.port and change the port number to match the one used by the external process
  3. Reopen the DSH-Web panel in the sidebar

When the extension detects a DSH process already running on the configured port, it will display a prompt: "External DSH Process Running". Click "Connect to Process" to load the web interface directly.

FAQ

Q: DSH cannot start?

A: Please check if port 3080 is occupied, or try modifying the port number in the configuration.

Q: What to do if connection times out?

A: Try clicking the "Restart Process" button in the top bar, which will kill the DSH process and restart it.

Q: DSH is installed, but still shows "DSH Not Installed"?

A: This may be due to installation status caching. Please try:

  1. Click the Refresh Connection button at the top of the sidebar
  2. If that doesn't work, restart VSCode (Ctrl+Shift+P → "Reload Window")
  3. Verify installation: run dsh --version in terminal

Q: DSH Web interface colors don't match VSCode theme?

A: DSH Web currently cannot automatically adapt to VSCode themes. You need to manually adjust the color mode in the DSH web interface settings.
